# Вопросы по git

Каждый пишет один вопрос и правильный ответ в свой раздел: про ветки, commit, push, pull, pull request или конфликт. Лучшие вопросы попадут в опрос на следующем занятии.

## Вопрос от Геннадий

Вопрос: почему надо писать  -u origin в комите, если ты ещё не делал git push после создания ветки?
Ответ: Потому что ветки ещё нету на github, git выдаст ошибку


## Вопрос от Индира

Вопрос: для чего нужна команда commit?
Ответ: для фиксации изменений и возможности отката
